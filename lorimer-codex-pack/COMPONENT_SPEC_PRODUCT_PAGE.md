# Component spec: Product page

## Goal

Minimal product detail page that feels consistent with the rest of the site.

## Layout

Desktop:
- large product image or gallery
- right detail column
- top aligned
- no dead center boxed module

## Detail hierarchy

- title
- price
- optional short copy
- size selection
- add to cart
- supporting info lower down

## Rules

- keep controls visually simple
- avoid overly app like selectors if plain text buttons work
- preserve white space
- preserve editorial tone
