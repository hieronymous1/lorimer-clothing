# Component spec: Navbar

## Purpose

The navbar should function like a masthead across the site.

## Desktop anatomy

Zone A:
- HOME

Zone B:
- S/S_24 or seasonal anchor

Zone C:
- centered brand wordmark

Zone D:
- SHOP

Zone E:
- ABOUT

This does not mean five equal columns.
It means five intentional anchors.

## Optical rules

- the brand must feel centered relative to the viewport, not mathematically distorted by unequal text widths
- HOME should not look too isolated
- SHOP and ABOUT should feel related
- the seasonal anchor should sit quietly, almost like a chapter marker

## Styling

- pale background
- serif or editorial style nav
- refined sizing
- no button chrome
- no chunky underline
- active state can be slight opacity or subtle line, but should remain quiet

## Hover

- very subtle color density shift
- no scale
- no big underline animation
