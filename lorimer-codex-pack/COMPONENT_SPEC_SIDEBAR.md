# Component spec: Shop sidebar

## Role

The sidebar is not a utility panel.
It is part of the fashion composition.

## Contents

- wordmark
- category list
- seasonal marker if needed
- collection filters

## Visual treatment

- text only
- no filter chips
- no heavy dividers
- no boxes
- no cards
- no icons

## Positioning

Desktop:
- strong left anchor
- preferably sticky if it supports the composition and does not break anything

## Typography

- same family logic as nav
- slightly larger than body but still refined
- compact vertical rhythm
