# Component spec: Product grid

## Role

The grid should feel like a curated presentation wall.

## Current problem

A centered grid inside a huge canvas feels cheap and unfinished.

## Correction

- relate the product field strongly to the sidebar
- use the page width more intentionally
- keep tall portrait image rhythm
- let whitespace exist around the cards, but stage it

## Desktop

Suggested:
- 3 columns
- tuned gaps, likely 32 to 56px
- rows with enough breathing room for image led presentation

## Tablet

- 2 columns likely
- keep images large enough

## Mobile

- 1 column preferred unless 2 truly works visually
