# Phase 07: Product page rebuild

## Prompt

Rebuild the product detail page so it feels minimal, spacious, and image first.

### Desired structure

Desktop:
- dominant product image or image column
- product information column beside it
- strong whitespace
- no cramped ecommerce module feeling

### Information hierarchy

- product title
- price
- concise description
- size / selection controls if present
- add to cart

### Rules

- keep the product image visually dominant
- avoid crowded accordions unless already essential
- do not use generic app like card containers
- preserve the same quiet luxury tone as the listing page

### Responsive

Tablet:
- keep image priority

Mobile:
- stack cleanly
- maintain good breathing room
- keep typography readable
- keep CTA accessible without making the page feel cheap

### Deliverable

Implement the product page rebuild and summarize:
- desktop composition
- mobile stacking
- remaining polish items
