# Layout specification

## Desktop shell

Use the full width more intentionally.

Recommended shell:
- full width root
- max width applied to the overall site shell only if needed, but avoid making the main shopping field feel boxed in
- strong left and right page paddings
- content should not collapse into a narrow centered lane

## Navbar

Recommended structure:
- explicit three zone or five zone grid
- left link group
- seasonal marker zone
- centered logo zone
- right link group
- optional empty spacer zone if needed for true optical balance

Avoid:
- simple `display: flex; justify-content: space-between;` for all nav content in one row
- equal width zones without testing optical center

## Home hero

Recommended structure:
- height: min 88vh desktop
- two panel field
- left image 50 to 52 percent
- right image 48 to 50 percent
- center seam crisp
- optional overlay image transparency if already used in current concept

## Shop page

Recommended shell:
- left rail 200 to 240 pixels
- main field starts closer to the rail than it currently appears
- products use 3 column grid on desktop with tuned gaps
- large top margin should be avoided unless it is intentionally part of the composition

Suggested desktop widths:
- sidebar: 220px
- gap between sidebar and content: 40 to 64px
- product columns: minmax tuned so cards feel tall and calm, not tiny

## Product page

Recommended shell:
- image area dominant
- content area narrower
- aligned top edges
- avoid giant centered product module

Possible ratio:
- image column 58 to 64 percent
- info column 36 to 42 percent
