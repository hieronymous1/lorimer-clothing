# Component spec: Product card

## Anatomy

- image
- title
- optional meta line

## Tone

The card should feel almost like a lookbook plate.

## Requirements

- image dominates
- title is modest
- alignment consistent
- metadata quiet
- avoid ecommerce chrome

## Hover

Subtle only:
- slight scale on image container or image itself
- maybe 1 to 3 percent
- smooth ease
- no shadow
- no hover card lift
