# Lorimer Codex Rebuild Pack

This pack is designed to help Codex rebuild the current Vercel site so it more closely matches the Framer reference in visual language, layout tension, spacing discipline, and responsive behavior.

## Inputs

Reference:
- Framer reference: https://full-point-623707.framer.app
- Current implementation: https://lorimer-clothing.vercel.app

Visual references used for this pack:
- `references/framer-home.png`
- `references/framer-grid.png`
- `references/vercel-shop.png`

## How to use

1. Put this folder in the repo root or upload the zip to Codex.
2. Start with `MASTER_PROMPT.md`.
3. Then paste `PHASE_01_AUDIT_AND_PLAN.md`.
4. Then execute the implementation prompts phase by phase.
5. Do not let Codex redesign freely. It should follow the system in this pack.

## Intent

The target is not “make it nicer”.
The target is:

- reduce template feeling
- restore editorial composition
- improve luxury perception through whitespace
- improve navbar hierarchy
- correct homepage hero behavior
- rebuild shop page proportions
- tighten responsive logic on tablet and mobile
