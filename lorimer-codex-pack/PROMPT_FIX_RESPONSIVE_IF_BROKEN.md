# Corrective prompt: if responsive behavior breaks

## Prompt

The desktop direction is improving, but responsive behavior still feels broken or generic.

Perform a dedicated responsive redesign pass instead of a shrink pass.

### Required actions

- review every main page at 1024, 768, 430, and 390 widths
- recompose the homepage hero for narrow screens
- prevent navbar compression and collisions
- redesign the shop layout for mobile instead of simply collapsing the desktop grid
- keep product cards image led and spacious
- keep the product page premium and readable on mobile

### Constraint

Do not throw away the editorial tone on small screens.
The mobile site should still feel like a fashion site, not like a generic store app.

List each responsive change you make by component.
