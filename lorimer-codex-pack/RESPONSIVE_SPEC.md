# Responsive specification

## Philosophy

Do not just shrink the desktop.
Recompose.

## Breakpoints

Suggested:
- 1440+
- 1280
- 1024
- 768
- 480 and below

## Desktop wide

- allow more breathing room
- avoid over stretching cards
- maintain quiet nav

## Tablet landscape around 1024

- navbar must remain stable
- shop sidebar may remain visible if it still feels elegant
- if sidebar remains, tighten width and gaps carefully
- if it collapses, do it intentionally, not by accident

## Tablet portrait around 768

- home hero likely needs a different crop strategy
- shop should likely move to a single main content flow with a lighter filter system
- cards should stay image first and not get too small

## Mobile

### Navbar
- simplify
- preserve brand
- do not overcrowd

### Home
- choose either:
  - stacked editorial image flow
  - single dominant crop with supporting secondary image lower down

Do not force a broken split screen on narrow width.

### Shop
- likely one column
- maybe two if imagery still reads clearly, but luxury tone usually benefits from one strong column if the cards are image led

### Product page
- image first
- title and price clear
- spacing generous for small screen
- add to cart accessible
